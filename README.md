# 個別指導塾 のびのびゼミ — Sample LP

架空の個別指導塾を想定した、生徒募集ランディングページのコーディングサンプルです。
塾名・料金・実績・生徒の声・キャンペーンなどはすべて架空のものです。

## 使用技術

- HTML5（WAI-ARIA、`details` / `summary` によるアコーディオン）
- Sass（SCSS）… 設定・ベース・共通パーツ・セクションごとにファイル分割、BEM命名
- JavaScript（バニラJS、ライブラリ不使用）

## 実装内容

- キャンペーン締め切りまでのカウントダウン（期限を過ぎると「受付終了」に切り替え）
- コース・料金のタブ切り替え（矢印キー・Home / End キーに対応）
- 生徒の声のスライダー（矢印・ドット・スワイプ・自動再生。PCは2枚、スマホは1枚表示）
  - マウスを乗せている間・キーボード操作中は自動再生を停止
- 実績のカウントアップ、スクロールに合わせたフェードイン
- 申し込みフォームの入力チェック、スマートフォン用の追従ボタン
- `prefers-reduced-motion` への配慮（動きを減らす設定の場合はアニメーションを停止）

## Sassのコンパイル

```bash
npm install
npx sass scss/style.scss css/style.css --style=expanded --no-source-map
```
